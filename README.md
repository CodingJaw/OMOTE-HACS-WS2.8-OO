# OMOTE Manager for Home Assistant

Development of a HACS-compatible integration for the OMOTE object-oriented firmware on the Waveshare ESP32-S3 2.8 V2.

Target baseline: Home Assistant Core 2024.9.1, Frontend 20240906.0, HACS 2.0.5.

The default branch is reserved for reviewed releases; development occurs on `develop`.

The firmware repository is maintained separately and is not modified by this project.
